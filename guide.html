그림일기 사용법

매일의 하루를 그림·사진·글로 남기는 나만의 일기장

📖 이런 앱이에요

달력의 날짜를 누르면 그날의 그림일기를 써요. 그림을 그리거나, 사진을 붙이거나, 글을 남길 수 있어요. 일기를 쓸수록 달력의 동그란 날짜들이 그날의 그림으로 하나씩 채워져서, 한 해가 예쁜 그림 갤러리가 돼요.

📅 첫 화면 (달력)

앱을 열면 이번 달 달력이 보여요.

1
날짜 동그라미
일기를 쓴 날은 그림으로 채워지고, 안 쓴 날은 숫자만 보여요. 아무 날짜나 누르면 그날 일기로 들어가요.
2
위쪽 ‹ 2026 › 화살표
연도를 앞뒤로 넘겨요. 그 아래 1월·2월… 줄을 누르면 달을 바꿔요.
3
아래쪽 탭 세 개
◫ 통계 — 얼마나 썼나 📅 달력 ◎ 갤러리 — 그림 모아보기
통계에서는 연도별로 며칠이나 썼는지 막대그래프로 한눈에 볼 수 있어요.

✏️ 일기 쓰기

날짜를 누르면 위에는 그림칸, 아래에는 글칸이 나와요.

1
기본은 ‘옮기기’ 모드예요 🖐 선택
그림칸의 사진이나 그림을 손가락(마우스)으로 끌어 옮기고, 네 모서리 동그라미로 크기 조절, 위쪽 손잡이로 돌리기(회전) 할 수 있어요. 처음엔 그림이 그려지지 않는 게 정상이에요.
2
그리려면 펜을 켜요 ✏️ 펜
펜 버튼을 누르면 그리기가 시작돼요. 여러 색과 굵기를 고르고, 지우개로 방금 그린 선을 지울 수 있어요. (지우개는 그림만 지워요 — 사진은 지워지지 않아요.)
3
사진 넣기 📷 사진
사진을 고르면 자르기 화면이 떠요. 흰 네모를 끌어 원하는 부분만 맞추고 적용을 누르면 그림칸에 들어가요. (용량은 자동으로 줄여 저장돼요.)
4
글 쓰기
그림칸 아래 줄 노트에 그날의 이야기를 적어요.
5
저장하기
다 됐으면 아래 저장하기 를 눌러요. 그러면 달력의 그 날짜가 방금 그린 그림으로 채워져요.
✎ 요소를 지우고 싶으면 그걸 한 번 눌러 선택한 뒤 🗑 를 눌러요. ⬆ 는 선택한 사진·그림을 맨 위로 올려줘요.

⚙ 배경 꾸미기

첫 화면 오른쪽 위 ⚙ 를 누르면 앱 배경을 바꿀 수 있어요.

프리셋 색감 6종 원하는 색 직접 📷 내 사진을 배경으로

☁ 폰이랑 컴퓨터 같이 쓰기

한쪽에서 쓴 일기를 다른 기기에서도 보려면 ‘클라우드 동기화(JSONBin)’를 한 번만 연결하면 돼요. 조금 길지만 처음 한 번만 하면 그다음부터는 저절로 돼요.

키가 두 종류예요.
· Master Key — 계정의 모든 걸 할 수 있는 만능 키. 편하지만, 이 앱은 주소가 공개돼 있어서 넣으면 위험해요(남이 보면 내 기록을 지울 수도 있어요).
· Access Key — 딱 필요한 권한만 주는 키. 이걸 쓰는 걸 추천해요.

① Access Key 만들기 (JSONBin 사이트에서)

1
jsonbin.io 로그인
가입돼 있으면 로그인만 해요.
2
API Keys → Access Keys → ‘Create Access Key’
메뉴에서 API Keys 페이지로 들어가 Access Keys 항목을 찾아요.
3
권한 3개 켜기
Bins의 Read Create Update 를 켜고 만들어요. (이 세 개가 있어야 읽기·새 Bin 만들기·저장이 다 돼요.)
4
만들어진 키 복사
생성된 Access Key 값을 복사해 둬요.

② 앱에 연결하기 (첫 기기)

1
⚙ → 클라우드 동기화
맨 아래에 Access Key (권장) / Master Key 고르는 버튼이 있어요. Access Key를 눌러 선택해요.
2
복사한 키 붙여넣기
키 칸에 방금 복사한 Access Key를 붙여넣어요.
3
새 Bin 만들기
처음이라면 이 버튼을 눌러요. Bin ID가 자동으로 채워져요. (일기를 담을 저장소가 하나 새로 생기는 거예요.)
4
연결·동기화
‘연결됨 · 동기화 완료’가 뜨면 끝. 이제 저장할 때마다 자동으로 올라가요.

③ 다른 기기에도 (폰↔컴퓨터)

1
⚙ → 동기화 → 📋 연결 링크 복사
이미 연결된 기기에서 이 버튼을 누르면 키·Bin ID가 담긴 링크가 복사돼요.
2
다른 기기에서 그 링크를 열면 끝
폰이든 컴퓨터든, 링크를 열면 자동으로 연결·동기화돼요. 키를 직접 입력할 필요 없어요.
⚠ 이 링크에는 내 데이터 열쇠가 들어 있어요. 나한테 보내는 용도로만 쓰고(카톡 나에게 보내기 등), 절대 남에게 공유하지 마세요.
안 될 때는
· ‘업로드 실패·받기 실패’가 뜨면 → 키 종류(Access/Master)를 맞게 골랐는지, Access Key에 Read·Create·Update 권한을 다 줬는지 확인해요.
· 사진을 많이 넣으면 저장 공간이 빨리 차요. 저장이 안 되면 오래된 일기나 큰 사진을 정리해 주세요.

💡 알아두면 좋은 것

  • 뒤로 ‹ 를 누르면 쓰던 내용이 자동 저장돼요.
  • 펜을 껐다 켜면, 그 사이 그린 선들이 하나의 그림 덩어리로 묶여요. 이어서 그리고 싶으면 펜을 켠 채로 계속 그려요.
  • 홈 화면에 바로가기(아이콘) 추가를 해두면 진짜 앱처럼 한 번에 열려요.
  • 같은 날짜를 폰·컴퓨터에서 각각 고치면, 나중에 저장한 쪽이 남아요.
이 페이지는 언제든 다시 열어봐도 돼요 🌿
